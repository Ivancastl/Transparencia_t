# Transparency Report Script

Este script permite interactuar con un conjunto de datos públicos relacionados con la transparencia de gobiernos en diferentes países. Los datos se obtienen desde un archivo JSON hospedado en GitHub y proporcionan información sobre la cantidad de solicitudes y usuarios por cada país en diferentes períodos de tiempo.

## Descripción

Este script permite:

1. Ver los reportes de transparencia de varios países.
2. Obtener información sobre las solicitudes y usuarios en un rango de fechas específico.
3. Filtrar y visualizar los datos por país.

## Requisitos

Este script requiere Python

## 📦 Instalación

1. Clona este repositorio:
    ```bash
    git clone https://github.com/Ivancastl/transparencia_telegram.git
    ```
3. Instala los requerimientos:
    ```bash
    cd Transparencia_t
    ```

2. Instala los requerimientos:
    ```bash
    pip install -r requirements.txt
    ```

3. Ejecuta el script:
    ```bash
    python telegram.py
    ```
